# 收敛冲刺计划：Phase日维度拆解+风险预案+回滚机制

> 版本：v1.0 | 创建：2026-06-12 | 来源：8D深度Review D5永久纠正方案A（收敛冲刺）
> 目标：真运行率从15%提升至60%，冻结所有新功能开发
> 时间窗口：6周（W1-W6）

---

## 核心原则

- **冻结新功能**：DR-88新功能预算=0%，100%资源用于DDoD提升
- **日维度拆解**：每周5个工作日，每天有明确里程碑+告警阈值
- **风险预案**：每个Phase预设风险点+缓解方案+回滚规则
- **回滚机制**：每个Phase结束时可回滚到上一个稳定点

| 风险 | 概率 | 影响 | 全局缓解 |

| DeepSeek API持续不可用 | 高 | 中 | 所有AI功能必须有纯手动降级方案(DR-52) |

| 上下文溢出/会话中断 | 中 | 中 | DR-85任务状态持久化+每日git tag |

## 回滚通用规则

1. 每个Phase D3结束创建git tag `sprint-pN-d3`
2. 回滚时 `git checkout sprint-pN-d3` + 重新构建部署
3. 回滚仅丢失D4-D5工作，D1-D3已验证的端到端闭环保留
4. Phase内部回滚不影响其他Phase
